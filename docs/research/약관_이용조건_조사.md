## 1. 한 장 요약

**결론 먼저**
1. **네이버 검색 API는 대안이 못 된다.** 2026-09-07 개정 검색 API 특약 2.3이 "데이터를 AI에 입력하거나 학습, 개선, 평가 및 노출 등에 활용하는 행위"를 금지한다. 2.2는 "가공 없이" 노출을 요구한다. 게다가 개발자센터의 검색 API **신규 신청은 2026-07-30 24:00에 중단**됐다(NAVER API HUB로 이관).
2. **키움 약관 원문을 찾았다.** 「오픈 API 서비스 이용약관」 제5조 ③: 시세 정보는 "개인의 업무에 한하여 이용해야 하며, 제3자에게 제공해서는 아니 된다". 팀 웹에서 다른 사람에게 시세를 보여 주는 지금 방식은 문언상 범위 밖이다.
3. **토스** 공식 FAQ "데이터 이용 정책": "비상업적인 용도라 하더라도 제 3자에게 배포하는 행위는 엄격히 금지".
4. **Google 뉴스 RSS**는 "개인 피드 리더에서 개인·비상업 용도로 결과를 보여 주는 것"만 허용한다. 여러 사람이 쓰는 서비스, LLM 입력, 제목 파싱은 모두 밖이다.
5. **OpenDART·공공데이터포털(재무·특일)은 허용**이다.
6. **저작권 위험은 낮다** — 교육용이라서가 아니라 제목·사실 정보만 쓰기 때문이다. 저작권법 제25조(학교교육)는 부트캠프 과제의 공개 배포에 기대기 어렵다.
7. **약관 위반은 교육·비상업 목적이어도 면제되지 않는다.** 현실적인 결과는 소송보다 **키 정지·접속 차단**이다. 발표(10/13)를 앞두고 이것이 가장 현실적인 위험이다.

### 2-3. 판단

피드가 허용한 범위와 우리 이용을 하나씩 맞춰 본다.

| 피드가 허용한 범위 | 우리 | 맞나 |
|---|---|---|
| personal feed reader (사람이 읽는 피드 리더) | 서버 프로그램이 자동 수집 → 스냅샷·DB·JSON | 아니오 |
| personal use | 팀원 5명 + 팀 밖 시험자 5명 | 아니오 |
| non-commercial | 광고·유료 없음 | 예 |
| rendering Google News results (결과를 그대로 보여 주기) | LLM 입력·요약, 정규식 파싱, 리포트 HTML·PDF에 저장 | 아니오 |

- "personal, non-commercial"은 **둘 다** 갖춰야 하는 조건이다. 비상업만 맞으므로 **여러 사람이 쓰는 비상업 교육용 웹 서비스는 범위에 들어가지 않는다** (판단).
- **LLM 입력은 "rendering"이 아니다.** 목표가 파싱은 데이터 추출이다. 둘 다 "Any other use"에 해당한다 (판단).
- 피드 문구는 동의 버튼 없이 붙는 방식이라 계약으로 묶이는지 다툴 여지가 있다. 약관규제법 제3조 ④는 명시·설명 의무를 어긴 약관을 "계약의 내용으로 주장할 수 없다"고 한다 [L4]. 다만 Google 서비스 약관의 "기타 콘텐츠" 조항이 같은 방향이고, 다툴 여지가 있다는 것이 "허용"을 뜻하지는 않는다 (판단).
- robots.txt는 원래 크롤러용이고 피드 리더에도 그대로 적용되는지는 불분명하다. 그러나 문언상 `/rss`는 모든 자동 수집기에 막혀 있고, Google 약관은 robots.txt 위반 접근을 금지 행위로 든다. 위험을 조금 더한다 (판단).
- **현실적 위험은 중간**이다. 소송보다 요청 차단(429·IP 차단)이나 피드 형식 변경이 먼저 올 것이다. 공개 시연 영상에 "Google 뉴스 제목을 AI가 요약"하는 장면이 나오면 범위 밖 이용이 공개 기록으로 남는다 (판단).

1. 저작권법 제23조~제35조의5는 "저작재산권의 제한", 즉 **저작권 침해 책임**에서 빼 주는 규정이다. 약관은 별개의 계약이다. 계약 위반에는 민법 제390조 "채무자가 채무의 내용에 좇은 이행을 하지 아니한 때에는 채권자는 손해배상을 청구할 수 있다"와 약정 해지(제543조)가 적용된다 [L3]. 저작권상 괜찮다고 계약 의무가 없어지지 않는다 (판단).
2. **약관 문언 자체가 교육·비상업 예외를 두지 않거나 명시적으로 배제한다**: 토스 "비상업적인 용도라 하더라도 … 엄격히 금지", 네이버 2.3 AI 입력 금지(예외 없음), 키움 "개인의 업무에 한하여", Google "personal, non-commercial"(둘 다 필요), 공공데이터 주식시세 "상업적 목적 여부와 상관 없이".
3. 위반의 1차 결과는 소송보다 **키 정지·해지·접속 차단**이다: 네이버 9.4·12.1, Google "suspend or terminate", 키움 해지. 발표 9일 전에는 이것이 가장 현실적인 위험이다.
4. 단서: 약관규제법 제3조 ④는 명시·설명 없이 체결한 약관을 "계약의 내용으로 주장할 수 없다"고 한다 [L4]. 동의 절차가 없는 Google 피드 문구는 다툴 여지가 있지만, 키움·네이버·토스는 가입 때 동의했으므로 해당하지 않는다 (판단).
5. 크롤링 형사 판례(2021도1533)는 약관·기술적 금지 조치가 사전에 있었는지를 따졌다는 해설이 있다 [C3]. 금지 문구가 분명한 출처를 쓰면 위험이 오히려 커진다 (판단).

## 8. "교육용 프로젝트라 상관없나" — 결론

**아니다.** 저작권은 대체로 괜찮다 — 다만 그것은 교육용이어서가 아니라 제목·사실만 쓰기 때문이다. 약관은 교육용이어도 그대로 적용되고, 우리가 쓰는 출처 대부분(Google 뉴스 RSS, 키움, 토스, 네이버)이 **비상업 이용도 다른 사람에게 보여 주는 것을 막는다.** 소송 가능성은 낮지만 키 정지·차단은 현실적이고, 공개 URL·공개 시연 영상은 범위 밖 이용을 공개 기록으로 남긴다.

## 9. 권고와 할 일 (담당 1 기준)

### 9-1. (a) 뉴스 출처

- **네이버 검색 API로 바꾸지 않는다.** 이유: ① 우리 핵심 용도(LLM 입력)를 특약 2.3이 명시적으로 금지한다 ② 목표가 파싱은 2.2 "가공 없이" 위반이다 ③ 개발자센터 신규 신청이 2026-07-30에 끝났고, NAVER API HUB 약관은 원문 미확인·유료 전환 예정이다. 사용자의 "네이버로 구현해도 됨"은 이 약관을 보기 전 결정이므로 다시 결정해야 한다 (`docs/결정필요사항.md` U5·E-3 갱신은 코디네이터).
- **발표(10/13)까지**: Google 뉴스 RSS를 유지하되 9-2의 표시·제한을 한다. 더 보수적으로 가려면 팀 밖 시험 기간에 뉴스 수집을 끈다(9-3 스위치).
- **발표 뒤**: LLM 근거를 OpenDART 공시 목록·재무·시세 수치 중심으로 바꾼다(공공데이터, 이용 제한 없음). 뉴스는 LLM에 넣지 않는 "원문 링크 목록"으로만 보이거나, 정식 이용 허락이 있는 출처를 검토한다. 후보: 한국언론진흥재단 빅카인즈 OPEN API(신청제, 이용 조건은 공개 페이지에서 못 읽음. 사이트 하단 "빅카인즈에서 제공되는 모든 기사는 「저작권법」의 보호를 받으며, 이를 전재, 복제, 배포하는 행위를 금합니다.") [B1].
- **해외(US)**: Google RSS는 같은 문제다. 대안으로 SEC EDGAR 공시 목록을 쓴다 — "Anyone can access and download this information for free", "Current max request rate: 10 requests/second", User-Agent 선언 필수 [E1 원문]. 8-K 등 공시 제목·날짜를 "오늘의 소식" 근거로 쓸 수 있다. 미국 뉴스 API(유·무료 플랜) 약관은 이번에 보지 않았다(10장).

### 9-4. (c) 발표 자료 고지 문구 (제안)

슬라이드 하단 한 줄:

> 비상업 교육 과제 · 실주문 없음 · 투자 권유 아님 · 시세: 키움증권 REST API · 공시/재무: 금융감독원 OpenDART·금융위원회 공공데이터 · 뉴스 제목: Google 뉴스(각 언론사) — 권리는 각 제공자에게 있음

긴 문장(마지막 장·영상 끝):

> 본 서비스는 비상업 부트캠프 교육 과제의 모의투자 시연입니다. 실제 주문은 없고 투자 권유가 아닙니다. 시세는 키움증권 REST API(조회 전용), 공시·재무는 금융감독원 OpenDART와 금융위원회(공공데이터포털), 뉴스 제목은 Google 뉴스 검색 결과(각 언론사)에서 받았으며, 모든 권리는 각 제공자에게 있습니다.

고지는 오해를 줄일 뿐 약관 위반을 없애 주지 않는다 (판단). 9-2의 제한과 같이 한다.

## 10. 확인 못 한 것

1. **토스증권 Open API 이용약관 전문** — 공개 페이지 없음(`/terms` 404). FAQ의 "데이터 이용 정책"만 원문 확인.
2. **NAVER API HUB 이용약관** — 콘솔 가입 단계에서 동의, 원문 미확인. 유료 전환 시기·요금 미확인.
3. **한국투자증권 고객용 「오픈 API 서비스 이용 약관(고객)」** — GitHub 이슈 2차 인용뿐. KIS 포털 약관 페이지는 스크립트로 그려져 읽지 못함.
4. **Google 뉴스 RSS 전용 약관** — 지금 공식 페이지 없음. 과거 비상업 웹 게재 라이선스는 2차 언급뿐이고 현재 효력 없음.
5. **피드 문구(동의 버튼 없는 약관)의 계약 성립** — 한국 판례 확인 안 함.
6. **뉴스 "제목"만 다룬 대법원 판례** — 못 찾음. 판례는 모두 요약 사이트(2차)로 확인했고 대법원 종합법률정보 원문은 읽지 않음.
7. **부트캠프 운영기관이 저작권법 제25조 ③ 각 호(특히 4호 학점인정 원격 과정)에 해당하는지** — 운영 형태 확인 필요.
8. **키움에 교육용 다중 표시 문의 결과** — 문의하지 않음(9-2 #7).
9. **빅카인즈 OPEN API 이용 조건** — 신청제, 공개 문서 못 찾음.
10. **미국 뉴스 API(Finnhub·Alpha Vantage·NewsAPI 등) 약관** — 이번 범위 밖.
11. **공공데이터포털 이용약관 자체** — 데이터셋별 이용허락범위만 확인.
12. 네이버 특약 9/7 개정 공지 원문 — 약관 본문과 보도로 확인, 개발자센터 공지 글 자체는 읽지 않음.
