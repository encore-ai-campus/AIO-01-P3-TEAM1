## 1. 한눈에

서비스 "모매매"는 AI 리포트 Agent 워크플로우(조사 → 작성 → 검토 → 추천)와 그 복구 계층, 그 결과를 모의 자동매매로 잇는 웹 서비스다.
다섯 명이 워크플로우의 한 층씩을 맡았고, 각자 자기 층의 설계·구현·테스트를 책임졌다.

| 담당 | 팀원 (브랜치) | 맡은 층 | 대표 산출물 |
|---|---|---|---|
| 1. 팀장·통합 | Hwanseok (`Hwanseok`) | 저장소·배포·통합, 추천 → 자동매매 연결, 운영 | CI/CD·EC2 배포, 담당 간 계약 문서, 자동 리포트, 관리 서버 |
| 2. Worker | dy (`dy`, `feat/2-worker`) | Worker와 출력 계약, 비용 예산 | 출력 계약 6종, Worker 공통 인터페이스, 하루 AI 비용 예산 |
| 3. Orchestrator | yubeen (`yubeen`) | 실행 계획 Registry와 Orchestrator 흐름 | YAML Registry 검증, 실행 흐름·timeout 대체 정책 |
| 4. AutoHealing | inhye (`inhye`, `feat/4-*`) | 장애 감지·복구와 지표 | 재시도·대체 모델·Circuit Breaker, 장애 주입, 복구 지표 API |
| 5. 프론트 | ju (`ju`) | 화면과 사용자 경험, 발표 | 공통 오류 화면, 오류·복구 시연, Agent Workflow 시연 화면, 발표 자료 |
