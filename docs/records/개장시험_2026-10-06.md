## 0. 먼저 알아 둘 것

- **화면의 가격은 장중에도 "10월 2일(금) 15:30 장마감 기준"이다** (사용자 결정, `docs/DECISIONS.md` 14-1). 장중 시세는 화면에 나오지 않고 **체결가·청산가만** 보인다.
  그래서 "체결됐는지"는 체결 알림·계획 상세·`모의투자` 탭으로 확인하고, 실제 시장 가격과 비교하려면 각자 증권사 앱을 본다.
- 모의 체결·청산 판단은 엔진(`run_engine`, 5초 루프)이 장중 확인 가격으로 한다. 지정가 매수는 확인 가격이 지정가 이하가 되면 **그 확인 가격**에 체결된다. 목표·손절은 **두 번 연속** 확인돼야 판다(약 10초 늦을 수 있다).
- **엔진 루프는 이 PC의 것 하나만** 돈다. 다른 PC에서 `run_engine`을 띄우지 않는다.
- 시세는 토스 조회(개발용)다. 원본 개인 프로젝트와 client를 같이 쓰므로 로그에 `token-revoked`가 보이면 엔진이 다시 받는다. 몇 루프 늦어질 수 있다 (`DECISIONS` 13-3).
- Discord는 아직 설정하지 않았다(U7 보류). 알림은 **웹 알림(종)만** 확인한다. `daily_move`·`thesis_check`는 원래 웹만이다 (단타 알림은 단타 폐기로 없어졌다).
- 공유 개발 DB를 쓴다. **시험 계정 둘**로만 주문한다(팀 계정·관리자 계정으로 주문하지 않는다). 실주문은 없다.
