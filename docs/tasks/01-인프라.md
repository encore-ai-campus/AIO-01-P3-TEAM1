## 주의

- Webhook 주소는 비밀 값이다 (`.env`·`.env.docker`에만. 로그·Trace·문서에 넣지 않는다). 테스트는 가짜 `urlopen`.
- 자동 리포트는 **매일 3건 × 실제 LLM 비용**이다. 하루 예산(`AI_DAILY_BUDGET_USD`)에 들어가게 2와 맞춘다. 시연 전까지는 `auto.tick()`을 호스트 PC에서만 돌리고, 필요하면 `AUTO_REPORT=off` 같은 끄기 스위치를 둔다 (`.env` 키 추가 시 `.env.example`에).
- `screen_market`은 증권사 조회를 100개 넘게 한다. 호출 제한에 걸리지 않게 하루 한 번만, 장 시작 전에.
- 엔진 컨테이너에는 openclaw가 없다. 운영의 Discord 발송은 Webhook이 유일한 길이다 (`docs/DEPLOY.md` 9장).
- EC2는 중지하면 공인 IP가 바뀐다 (`docs/DEPLOY.md` 9장). 운영 중에는 중지하지 않는다.
- `main` 직접 push는 허용이지만, 팀 작업 중에는 PR로 올려 CI를 거치는 것을 권한다. 급한 고침만 직접.
